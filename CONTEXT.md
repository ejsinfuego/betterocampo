# Better Ocampo

Independent community guide for the Municipality of Ocampo, Camarines Sur. Includes a community intake channel for infrastructure concerns.

## Language

### Reporting

**Report**:
A citizen-raised concern about public infrastructure or the local environment (road, bridge, drainage, and similar).
_Avoid_: Issue, ticket, complaint, request, bug report

**Report a problem**:
The citizen-facing action of submitting a Report so it can be raised with the municipality.
_Avoid_: File a Report, Report an issue, Submit a ticket, Magsumbong, Tell the LGU (button label — too absolute for this community channel)

**Reference ID**:
A short unguessable receipt identifier that lets anyone track one Report without an account.
_Avoid_: Tracking number, case ID, ticket ID

**Status**:
Where a Report sits in community triage: Received, In review, Resolved, or Closed.
_Avoid_: State, stage, progress

**Visibility**:
Whether a Report is Private (default) or Published (approved for the public board).
_Avoid_: Public flag, disclosed, shared

**Publish**:
An admin action that creates a redacted public projection of a Report for the community board.
_Avoid_: Approve for LGU, release, post

**Unpublish**:
An admin action that removes a Report from the public board and returns it to Private.
_Avoid_: Hide, retract, unapprove

**Soft-delete**:
An admin action that hides a Report from normal admin lists and tracking without permanently erasing it.
_Avoid_: Delete, archive, purge

**Community intake**:
The framing of this channel: reports are collected by site operators and may be shared with the municipality; this is not an official LGU filing or a guarantee of repair.
_Avoid_: Official LGU ticket, municipal complaint system
